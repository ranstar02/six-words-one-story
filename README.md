A six-word story in a program that writes it to `entry.txt`. One empty chair at the Christmas table says everything about who is gone, without ever naming the loss.

## The story

> Grandfather's chair stayed empty at Christmas.

Exactly six words, 46 characters — a complete story with a whole life implied and something left unsaid for the reader to fill in.

## Run

```bash
python3 main.py
```

This writes the story to `/output/entry.txt` (or `./output/entry.txt` if `/output` is not writable).
